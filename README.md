# Примитивная база данных primitive-db

Консольное приложение, имитирующее работу с базой данных: позволяет создавать
и удалять таблицы с типизированными столбцами, хранит структуру таблиц в
JSON-файле на диске.

## Управление таблицами

Доступные команды:

- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать
  таблицу. Столбец `ID:int` добавляется автоматически первым. Поддерживаемые
  типы столбцов: `int`, `str`, `bool`.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `list_tables` — показать список всех таблиц.
- `help` — показать справку по командам.
- `exit` — выйти из программы.

## CRUD-операции

Доступные команды для работы с данными внутри таблиц:

- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — создать
  запись. `ID` генерируется автоматически, его передавать не нужно. Строковые
  значения из нескольких слов должны быть в кавычках (например, `"Иван Иванов"`).
- `select from <имя_таблицы>` — прочитать все записи таблицы.
- `select from <имя_таблицы> where <столбец> = <значение>` — прочитать записи,
  подходящие под условие.
- `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` —
  обновить подходящие записи.
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить
  подходящие записи.
- `info from <имя_таблицы>` — информация о таблице

Поддерживаемые типы значений: целые числа (`28`), строки (`"Sergei"`),
булевы значения `true`/`false`.
