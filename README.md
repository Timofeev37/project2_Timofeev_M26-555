# Примитивная база данных primitive-db

Консольное приложение, имитирующее работу с базой данных: позволяет создавать
и удалять таблицы с типизированными столбцами, хранит структуру таблиц в
JSON-файле на диске.

## Управление таблицами

Доступные команды:

- `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создать
  таблицу. Столбец `ID:int` добавляется автоматически первым. Поддерживаемые
  типы столбцов: `int`, `str`, `bool`.
- `drop_table <имя_таблицы>` — удалить таблицу.
- `list_tables` — показать список всех таблиц.
- `help` — показать справку по командам.
- `exit` — выйти из программы.
